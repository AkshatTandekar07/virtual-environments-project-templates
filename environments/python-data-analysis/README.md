# Python Data Analysis Environment

A lightweight environment for data manipulation, cleaning, and visualization.

## Setup Instructions

1. Copy this folder (or just the `requirements.txt` file) to your new project directory.
2. Open your terminal in the new directory.
3. Create a virtual environment:
   ```powershell
   python -m venv venv
   ```
4. Activate the environment:
   ```powershell
   venv\Scripts\activate
   ```
5. Install the dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
6. Start Jupyter Notebook (if you want to work in notebooks):
   ```powershell
   jupyter notebook
   ```
