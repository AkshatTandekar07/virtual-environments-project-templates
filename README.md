# Virtual Environments & Project Templates

A personal collection of virtual environment configurations and boilerplate project templates. I use this repository to quickly bootstrap new projects with standardized environments, dependencies, and folder structures.

## 📂 Repository Structure

*   **`/virtual-envs/`** (Coming Soon): Contains scripts and configurations (e.g., `requirements.txt`, `environment.yml`, `package.json`) for setting up common development environments.
*   **`/templates/`** (Coming Soon): Boilerplate code and folder structures for various types of projects (e.g., Python APIs, Web Apps, Data Science workspaces).

## How to Use

### Using a Project Template
To start a new project using one of the templates:
1. Copy the desired template folder to your new project directory.
2. Follow the specific instructions inside the template's `README.md`.

### Setting up a Virtual Environment
To set up an environment for a project:
1. Navigate to your project directory.
2. Use the configuration file from the relevant `/virtual-envs/` folder to install dependencies.

*(Example for Python: `python -m venv venv` and `pip install -r requirements.txt`)*
